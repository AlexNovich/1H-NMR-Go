# NMR-go 0.12.0

First public release for Windows 11 x64. NMR-go opens Bruker 1D proton experiments
from ZIP archives or folders and runs offline.

Open processed data or process a raw FID, preview phase and baseline changes,
integrate signals, pick peaks with clicks or a rectangle, and export a vector PDF.
Use Save annotations to store integrals and peaks in the selected processed spectrum.

To start, download the complete Windows x64 ZIP from GitHub Releases, extract it,
and run `NMR-go.exe`. Try the anonymized Bruker example linked from the README.
